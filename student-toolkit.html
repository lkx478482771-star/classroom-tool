欢迎使用集成电路学习工具箱

这是一个面向安徽大学的本地学习工具箱，数据默认只保存在当前浏览器中。

  • 我的专业：内置集成电路设计与集成系统路线，也可以新建自己的模板。
  • 专业路线：按学期勾选成长任务，进度自动保存在本机。
  • 网址导航：校园入口、学习资源和常用网站分类整理，也可以自己添加，下次打开自动保留。
  • 搜索：快速查找任务、学习资源和页面模块。
  • 数据备份：清除浏览器数据或更换设备前，先导出 JSON 备份。

云端账号、自动成绩同步和教务 API 需要后端服务，纯静态 GitHub Pages 暂不支持。
