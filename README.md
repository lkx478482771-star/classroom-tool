# 安大学生工具箱

面向安徽大学的静态学习工具箱，包含专业成长路线、倒计时、校历、课表导入、竞赛节点、学习资源、数据备份和课堂整理等功能。

## 主要功能

- 专业模板：集成电路、微电子、财经、经济管理，支持自定义模板导入导出
- 成长路线：任务勾选、筛选、学年统计、截止日期、优先级、备注、链接和状态
- 校历与倒计时：校历事件一键加入倒计时
- 到期提醒：汇总任务和倒计时，支持浏览器通知
- 课表导入：粘贴课表文本或手动添加课程
- 竞赛节点：支持新增竞赛，标记报名、初赛、决赛并加入倒计时
- 学习与校园资源：专业网站、图书馆、知网、万方、IEEE 等入口
- 数据备份：导出和恢复浏览器本地数据
- 全局搜索、新手引导、深色模式
- 课堂整理：课程笔记、待办、语音记录和 AI 总结

## 数据保存

除 AI 接口调用外，数据默认保存在浏览器 `localStorage` 中，不会自动上传服务器。

清除浏览器数据、更换设备或更换浏览器前，请先在“数据备份”中导出 JSON 文件。

## 本地预览

```powershell
cd outputs\classroom-tool
python -m http.server 8010
```

然后访问 `http://127.0.0.1:8010/index.html`。

不要直接用 `file://` 打开，否则 Service Worker、离线缓存和部分相对路径功能会失效。

## 部署

- GitHub Pages：当前仓库可直接作为静态站点部署。
- Netlify / Vercel：无需构建命令，发布目录设置为仓库根目录。
- 详细说明见 [DEPLOY.md](DEPLOY.md)。

## 静态站点限制

以下功能需要后端服务，GitHub Pages、Netlify 和 Vercel 的纯静态托管本身无法实现：

- 用户账号登录
- 多设备云端同步
- 直接调用智慧安大 API 自动拉取成绩或课表
- 服务端数据库和权限管理

跨设备迁移目前只能通过“数据备份”手动导出和导入 JSON。
